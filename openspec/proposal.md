# Мини-трекер учебных задач на неделю

## Why

Нужен автономный мини-трекер для управления учебными задачами на неделю:
добавлять и удалять задачи, отмечать выполнение и видеть прогресс по часам.

## What Changes

- Задача содержит id, title, hours и done.
- При открытии загружается стартовый пример:
  - «Чтение»: 2 ч, выполнено.
  - «Практика»: 4 ч, активно.
  - «Повторение»: 2 ч, активно.
- Доступны добавление, удаление и переключение выполнения.
- Форма проверяет название и часы, показывает ошибки рядом с полями
  и сохраняет введённые значения при ошибке.
- Фильтры «все / активные / готовые» меняют только видимый список.
- Сводка показывает часы всех задач, выполненные часы и прогресс по часам.
- Интерфейс читаем при ширине 390 px, без горизонтального скролла;
  поля и кнопки подписаны.

## Capabilities

### New Capabilities

- tracker: управление учебными задачами, валидация, фильтрация и сводка.

### Modified Capabilities

Нет.

## Границы

Предусмотрены два варианта упаковки одной функциональности:

- A: один tracker-v2.html со встроенными CSS и JavaScript.
- B: index.html, styles.css, app.mjs, domain.mjs,
  tests/acceptance.test.mjs.

Выбор варианта относится к отдельному запросу на реализацию.
Приложение работает автономно, без CDN, внешних библиотек и API-ключей.

«На неделю» описывает назначение трекера; календарь, даты и переключение
недель в объём работ не входят. Другие функции не добавляются.

Сохранение между перезапусками через localStorage — необязательное
улучшение. При открытии через file:// его поведение зависит от браузера,
поэтому сохранение между запусками в этом режиме не гарантируется.

## Impact

- Реализация ограничена файлами выбранного варианта.
- Сервер и внешние ресурсы не требуются.
- Этот запрос создаёт только спецификацию; реализация выполняется
  отдельным запросом.
