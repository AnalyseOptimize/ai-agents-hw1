# Данные и расчёты

## Модель

| Поле | Тип | Правило |
| --- | --- | --- |
| id | строка | Уникальный и стабильный идентификатор задачи |
| title | строка | Непустое значение после trim |
| hours | число | От 0,5 до 24 включительно, кратно 0,5 |
| done | логическое | true — готово, false — активно |

Состояние приложения: массив задач и выбранный фильтр.
Начальный фильтр — «все».
Сводка вычисляется из массива задач, отдельно не хранится.

## Стартовые данные

| title | hours | done |
| --- | --- | --- |
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |

Каждая стартовая задача получает собственный id.

## Валидация

1. Проверить название после trim.
2. Проверить отсутствие ввода часов до преобразования в число.
3. Проверить, что часы являются конечным числом.
4. Проверить диапазон: 0,5 ≤ hours ≤ 24.
5. Проверить шаг: удвоенное значение hours является целым числом.
6. При любой ошибке оставить данные задач и значения формы без изменений,
   показать ошибки рядом с соответствующими полями.
7. При успехе сохранить обрезанное название, числовые часы и done=false.

Пустое значение, ноль и отрицательные значения недопустимы.
Проверка HTML-поля не заменяет проверку данных перед добавлением.

## Расчёты

- H — сумма hours всех задач.
- D — сумма hours задач с done=true.
- P — 0, если H=0; иначе округление 100 × D / H
  до ближайшего целого, с округлением половины вверх.

Вычисления выполняются по всему массиву, до фильтрации.

Контрольные значения:

| Состояние | H | D | P |
| --- | --- | --- | --- |
| Стартовый пример | 8 | 2 | 25% |
| «Практика» выполнена | 8 | 6 | 75% |
| Задач нет | 0 | 0 | 0% |
| Выполнено 0,5 ч из 1,5 ч | 1,5 | 0,5 | 33% |

## Изменения и отображение

Добавление создаёт новую запись; удаление находит запись по id;
переключение меняет done выбранной записи.

После изменения пересчитывается сводка и строится видимый список:

- «все»: все задачи;
- «активные»: done=false;
- «готовые»: done=true.

Фильтрация не удаляет записи и не меняет знаменатель прогресса.
Длинные названия переносятся; элементы формы и строки задач
размещаются в пределах ширины 390 px.

## Варианты упаковки

### A

tracker-v2.html содержит разметку, стили и JavaScript.
Файл предназначен для непосредственного открытия в браузере.

### B

- index.html: разметка и подключение локальных файлов.
- styles.css: стили.
- app.mjs: форма, события, отображение и связь с доменной логикой.
- domain.mjs: валидация, изменение задач, фильтрация и расчёты без DOM.
- tests/acceptance.test.mjs: проверки доменной логики встроенными
  средствами Node.js, без внешних тестовых библиотек.

ES-модули при открытии через file:// могут блокироваться браузером.
Поэтому вариант B рассчитан на раздачу файлов по локальному HTTP;
интернет и внешний сервер не требуются. Запуск тестов требует Node.js,
работа самого интерфейса — браузера.

## Необязательное хранение

Базовая версия держит задачи в памяти и при новом открытии
инициализирует стартовый пример.

Если включено localStorage:

- при отсутствии сохранённого состояния используется стартовый пример;
- сохранённый пустой массив считается существующим состоянием;
- успешные изменения сохраняются;
- ошибки чтения и записи обрабатываются без остановки приложения;
- при сбое показывается сообщение, что изменения текущего сеанса
  доступны в памяти, но сохранение между запусками недоступно.

При file:// доступность и поведение localStorage зависят от браузера.
Нельзя обещать сохранение между перезапусками для этого режима.
